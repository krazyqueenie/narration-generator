\# Narration Tool



A simple Windows narration generator for turning written text into spoken audio.



The tool supports multiple languages and voices, allows users to preview generated narration, and download the finished audio file.



\## Features



\- Multiple language support

\- Multiple voice options

\- Text-to-speech narration generation

\- Generation progress indicator

\- Audio preview

\- Audio download

\- Simple Windows interface

\- Source code included for transparency



\## Using the App



For the easiest setup, use the packaged Windows EXE version.



The source code is also provided for users who want to inspect, learn from, modify, or build the project themselves.



\## Running From Source



Running the source version requires Python to be installed on your computer.



1\. Install Python if it is not already installed.

2\. Run the included setup file once to install the required Python packages.

3\. Double-click `2. Start Narration Tool.vbs` to open the narration tool.



Python may automatically create a `\_\_pycache\_\_` folder while the program runs. This folder is temporary and is not required for the project.
